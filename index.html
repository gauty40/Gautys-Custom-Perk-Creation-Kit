FROM WORKSHOP TO WUNDERFIZZ

Install & test

A few steps between your pack and your next match.

01

Review and export.

Check perk IDs, codes, creator credits, augment names, and your actual GSC effects. Download the ZIP below. You can import this ZIP again to continue editing.

02

Back up. Then install.

Extract the ZIP and copy its kronos folder into your cod25 folder, merging folders. Install the same gameplay scripts on every co-op PC.

03

Clear old compiled scripts.

Delete matching .gscc files in kronos/custom_scripts/compiled for every changed or removed GSC, then fully restart. Remove the source scripts listed in REMOVED_PERKS.txt too.

04

Test your perk in-game.

Check buying, removal, reacquisition, each augment and different co-op selections. The site validates definitions and Lua syntax. GSC compilation happens in Kronos and in-game behavior still needs testing.

05

Refresh custom artwork.

For new perk-pack images run the exported Refresh-PerkIconPacks.ps1; for eternal frame folders run Refresh-EternalPerkFrames.ps1. Fully restart after importing images.

Use your latest project ZIP or import your installation folder to preserve changes outside the bundled snapshot. Unsaved browser work is lost on reload—export a ZIP to save it.
